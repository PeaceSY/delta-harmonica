# 三角洲口琴助手 · 下载页

八音键口风琴自动演奏工具(把 MIDI / 简谱 / 音频编译成按键与鼠标修饰键序列,自动演奏)。

> **本仓库只放可执行文件的发布包,不含源代码。**

## 下载安装

1. 打开本仓库的 [**Releases**](../../releases) 页面;
2. 在最新版本里下载 **`口琴助手.exe`**(约 145MB——体积大是因为内置了音频转谱模型);
3. 双击运行即可,**无需安装**。要求 **Windows 10 / 11(64 位)**。

首次运行若弹出 Windows SmartScreen「已保护你的电脑」:
点【**更多信息**】→【**仍要运行**】——这是未做代码签名的正常提示,不是病毒告警。

## 怎么用

| 步骤 | 操作 |
| --- | --- |
| 1. 加曲目 | 点【**导入文件**】:支持 MIDI(`.mid/.midi`)、简谱(`.txt/.jianpu`),以及**音频自动转谱**(`.mp3/.wav/.flac/.ogg`);也可以点【写简谱】手抄 |
| 2. 调参数 | 速度、移调、风格(自动旋律 / 原谱分音 / 钢琴连奏)、片段范围 |
| 3. 去演奏 | 切到**英文输入法**、把目标程序设为**窗口化 / 无边框**,点【播放】;倒计时后自动按键,**F9 紧急停止** |

转谱参数**默认全自动**(调性、大小调、量化精度、音域都由歌曲自动识别),不需要懂乐理;想手动干预再展开【高级设置】。

## 关于激活码

首次使用【导入文件 / 写简谱 / 上传曲目】需要输入 **16 位激活码**(格式 `XXXX-XXXX-XXXX-XXXX`),
播放已入库曲目不受限制。**一个激活码只绑定一台电脑**,不支持换机。
获取方式请联系作者本人。

## 常见问题

- **设置和曲库存在哪?** `%LOCALAPPDATA%\口琴助手`。删掉这个文件夹即完全卸载(激活状态也会一并清除)。
- **为什么文件这么大?** 内置了离线音频转谱模型,不需要联网、不需要额外下载。
- **卡在"正在转录"?** 转谱在本地跑,CPU 上约实时 1 倍速(4 分钟的歌要几分钟),可以随时取消。
